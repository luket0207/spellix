Test Status

* in progress

Manual Test Steps

1. Run `npm start` and open the local URL.
   Expected: The development server loads the app at `/`, assets load, and hash-based navigation works without requiring `/spellix/` locally.
2. Select New Game, return home, open Rules, and inspect Load Game.
   Expected: Existing local routes and all three home actions continue to work.
3. Run `npm run build` and inspect `build/index.html`.
   Expected: The optimized build succeeds and generated asset URLs begin with `/spellix/`.
4. Run `npm run deploy` after the source setup commit is pushed.
   Expected: The build runs again, the first deployment commit is published to a new remote `gh-pages` branch, and source files are not deployed directly.
5. Configure GitHub Pages to deploy the root of `gh-pages`, then open `https://luket0207.github.io/spellix/`.
   Expected: The public game loads with its starry background and player, token, enemy, and feature images intact.
6. Navigate through New Game and Rules on the deployed site, refresh a hash route, and inspect the console.
   Expected: Routes continue to work after refresh and there are no critical asset-path or runtime errors.
