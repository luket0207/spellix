Feature-001: Add Anywhere Mode debug movement tool

Status

* done

Goal

* Add a new debug tool that allows the admin to enable `Anywhere Mode` for the current player.
* Anywhere Mode gives the current player an infinite movement option for their next turn.
* When active, the player should be able to select and move to any valid square on the map.

Scope

* Update the existing debug modal from EPIC-003.
* Add an `Anywhere Mode` control to the debug modal.
* The debug tool should apply only to the player whose turn it currently is.
* Anywhere Mode should apply to that player’s next movement opportunity.
* When Anywhere Mode is active, the player should be able to move anywhere on the board.
* After the player uses Anywhere Mode to move, Anywhere Mode should turn off for that player.
* Keep this as debug/admin functionality only.
* Keep the UI simple and functional.

Debug Menu Requirement

* The debug modal should include a new control labelled:

```txt id="5rqgkp"
Anywhere Mode
```

* The debug modal should make clear that Anywhere Mode applies to the current player only.
* The debug modal should show whether Anywhere Mode is currently enabled for the current player.
* The admin should be able to turn Anywhere Mode on for the current player.
* A simple button or checkbox is acceptable.
* Keep the debug modal scrollable as required by the existing debug menu feature.

Player State Requirement

* Anywhere Mode should be tracked per player.
* Suggested player state:

```js id="g5r42n"
{
  anywhereMode: false
}
```

* Turning on Anywhere Mode from the debug modal should set it for the current player only.
* One player having Anywhere Mode should not affect any other player.
* Anywhere Mode should remain active until that player uses it to move.
* After the player moves using Anywhere Mode, set their `anywhereMode` back to `false`.

Movement Requirement

* If the current player has Anywhere Mode active:

  * They should effectively have an infinite dice roll.
  * They should be able to select any valid board square as their movement destination.
  * Legal destination highlighting should show that the player can move anywhere valid.
  * Normal dice distance should not restrict their movement.
* The player should still move by selecting a destination square.
* Once the destination is selected and movement completes, Anywhere Mode should be consumed.
* Turn flow should then continue normally.

Valid Destination Requirement

* Anywhere Mode should allow movement to normal valid board squares.
* Do not allow movement onto invalid or non-playable squares if any exist.
* Do not allow movement outside the board.
* Do not allow movement to missing board data.
* If fixed areas, grouped areas, or feature areas already have special movement rules, preserve them where practical.
* The current player’s current square should not need to be highlighted as a destination.
* The current player should not be able to select their current square as a move destination unless the existing movement system already allows staying still.

Interaction With Existing Movement Rules

* Anywhere Mode should override normal dice distance.
* Anywhere Mode should override river blocking distance restrictions because the player can move anywhere.
* Anywhere Mode should override Start Area return restrictions only if the target square would otherwise be considered a valid board square.
* If the Start Area should remain blocked even for debug movement, keep it blocked only if that is simpler and safer.
* Do not change the normal movement rules for players without Anywhere Mode.
* Do not change dice rolling for normal turns.
* Do not permanently change the dice result system.

Expected Behaviour

* The debug modal contains an Anywhere Mode control.
* The admin can enable Anywhere Mode for the current player.
* Anywhere Mode applies only to the current player.
* When Anywhere Mode is active, that player can move to any valid board square.
* Normal movement range does not limit the player while Anywhere Mode is active.
* River blocking does not limit Anywhere Mode movement.
* After the player moves, Anywhere Mode turns off.
* Other players are unaffected.
* Later turns return to normal movement unless Anywhere Mode is enabled again.
* Existing debug token tools still work.
* Existing settings menu still works.
* Existing movement still works for non-Anywhere Mode players.

Out Of Scope

* No player selection inside the debug menu.
* No applying Anywhere Mode to all players.
* No permanent infinite movement mode.
* No teleport animation.
* No special visual effects.
* No new dice UI.
* No changes to normal dice roll values.
* No changes to board generation.
* No changes to river generation.
* No changes to Start Area generation.
* No changes to player pieces.
* No changes to spells.
* No changes to token bag rules.
* No save/load functionality.
* No persistence.
* No unrelated debug tools.

Assumptions

* “Current player” means the player whose turn it currently is.
* “For the next turn” means for that player’s next movement action, then it is consumed.
* Anywhere Mode is a debug/admin tool and does not need to be balanced for normal gameplay.
* Anywhere Mode should use the existing movement selection flow where possible.
* The simplest implementation is to make every valid board square selectable while Anywhere Mode is active.

Stop Point

* Stop once the debug modal can enable Anywhere Mode for the current player, that player can move to any valid board square, and Anywhere Mode is consumed after the move.

* Confirm a player with Anywhere Mode can move to the selected square.
* Confirm Anywhere Mode is consumed after movement.
* Confirm the player returns to normal dice movement on their next turn.
* Confirm other players continue using normal movement.
* Confirm river blocking does not prevent Anywhere Mode movement.
