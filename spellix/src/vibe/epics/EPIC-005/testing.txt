Test Status

* passed

Feature Coverage

* The Debug modal now shows an `Anywhere Mode` control, a current-player-only scope note, and enabled/disabled status for the current player.
* Enabling Anywhere Mode affects only the current player and leaves other players unchanged.
* While Anywhere Mode is active, Gameplay highlights every valid board node except the current node and lets the player move far beyond normal dice range.

* Existing debug token tools, settings access, and normal non-Anywhere movement remain intact.

Expected result: Valid destinations across the board can be selected even far outside normal dice range, while the current square itself is not highlighted as a destination.

4. Select a far destination square and complete the move.
Expected result: The player moves to the selected square successfully, including across rivers or back onto the Start Area if chosen, and turn flow continues normally.

5. Continue play until that same player gets another turn and roll again without re-enabling Anywhere Mode.
Expected result: Anywhere Mode has been consumed, so the player returns to normal movement highlighting and range rules.

6. Reopen Debug and use the existing token-giving tools.
Expected result: Debug token tools still work as before.
