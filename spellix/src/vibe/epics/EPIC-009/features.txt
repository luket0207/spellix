Feature-001: Reduce board features and update feature placement rules

Status

* done

Implementation Notes

* Reduced generated features to exactly one easy-section feature and one hard-section feature.
* Kept each 2x2 feature's occupied squares between coordinates 7 and 23, giving seven-square clearance from every edge of the 31x31 board.
* Increased occupied-square Chebyshev clearance from fixed areas and the other generated feature to at least seven squares, including diagonally.
* Preserved the existing fixed-area, protected Start Area field zone, section, environment, and feature collision checks.
* Added a 50-attempt random placement limit followed by an exhaustive valid fallback. Development builds warn and omit the feature rather than silently place an invalid one if no valid candidate exists.

Goal

* Reduce the number of generated board features.
* Features are the yellow locations currently generated on the board.
* There should now be only 2 generated features on the whole board:

  * 1 feature in the easy section.
  * 1 feature in the hard section.
* Features should be positioned more centrally by keeping them away from map edges and away from each other.

Scope

* Update board feature generation.
* Reduce generated feature count.
* Add stricter edge-distance rules.
* Add stricter feature-to-feature distance rules.
* Preserve existing fixed board areas.
* Preserve existing board environment generation unless affected by feature placement.
* Preserve existing feature visual styling unless required by the reduced count.

Generated Feature Count Requirement

* The board should generate only:

```txt id="4f6k8r"
2 features total
```

* These should be split as:

  * 1 generated feature in the easy section.
  * 1 generated feature in the hard section.
* Do not generate 3 easy and 3 hard features anymore.
* Do not generate 6 total features anymore.
* Do not generate more than 2 generated features unless a future feature changes this again.

Easy / Hard Section Requirement

* One feature must be placed in the easy section.
* One feature must be placed in the hard section.
* Continue using the existing easy/hard board split logic unless another feature has changed it.
* The easy feature should be fully inside the easy section where possible.
* The hard feature should be fully inside the hard section where possible.
* Do not allow both features to generate in the same section.

Edge Distance Requirement

* Features should always be at least:

```txt id="7cseuq"
7 squares away from the edge of the map
```

* This applies to every edge:

  * top edge.
  * right edge.
  * bottom edge.
  * left edge.
* For a 31×31 board, this means generated feature top-left placement must be constrained so the whole feature remains at least 7 squares from the board edge.
* The exact coordinate bounds should account for the size of the feature.
* Do not place a feature so any part of it is within 7 squares of the edge.

Feature Distance Requirement

* Features should always be at least:

```txt id="xffdoo"
7 squares away from each other
```

* This distance should include diagonal distance.
* Features should not be allowed to be too close diagonally.
* Use a clear distance check based on the occupied area of each feature, not only the top-left coordinate if possible.
* The easiest acceptable rule is to reject a new feature if its occupied squares are within 7 squares of any occupied square of another feature.
* Existing fixed feature-like areas should also be considered if they are part of the current feature collision system.

Generated Feature Placement Requirement

* Generated features should not overlap:

  * Start Area.
  * protected Start Area field zone.
  * Elite Battle areas.
  * Boss Battle area.
  * other generated features.
  * water where existing rules prevent feature placement.
  * any other non-overwritable fixed area.
* Existing feature placement exclusions should remain in place unless they conflict with the new stricter rules.
* The new 7-square edge distance and 7-square feature distance rules should be added on top of existing exclusions.

Central Placement Intent

* The stricter edge distance should make features appear more toward the middle of the board.
* The stricter feature distance should keep the two features separated.
* Do not force features to the exact centre.
* Random generation is still fine as long as the rules are respected.
* If many attempts fail, use a safe retry strategy rather than placing invalid features.

Retry / Fallback Requirement

* Feature generation should retry if a candidate violates the new rules.
* Avoid infinite loops.
* Use a maximum attempt count.
* If placement fails after reasonable attempts:

  * log a clear warning in development.
  * use the best valid fallback available.
  * do not break board generation.
* Do not place invalid features silently.

Expected Behaviour

* A newly generated board has exactly 2 generated yellow features.
* One generated feature appears in the easy section.
* One generated feature appears in the hard section.
* Both features are at least 7 squares away from all map edges.
* The two generated features are at least 7 squares away from each other, including diagonally.
* Features generally appear nearer the middle of the map than before.
* Existing fixed areas still appear correctly.
* Board generation still completes reliably.

Out Of Scope

* No new feature types.
* No changes to feature visuals.
* No changes to Elite Battle areas.
* No changes to Boss Battle area.
* No changes to Start Area.
* No changes to battle triggering.
* No changes to environment generation except avoiding invalid feature placement.
* No changes to movement rules.
* No changes to minimaps or UI labels.
* No unrelated board generation redesign.

Assumptions

* Features are currently generated as yellow locations.
* Existing generated features are separate from fixed Elite/Boss/Start areas.
* The board still uses a 31×31 grid.
* Easy and hard sections are already identifiable during generation.
* Feature size and occupied squares can be checked during placement.

Stop Point

* Stop once the board reliably generates exactly 2 yellow features, one easy and one hard, both at least 7 squares from the map edge and at least 7 squares from each other.

Testing Checkpoints

* Generate a new board.
* Confirm only 2 generated yellow features appear.
* Confirm 1 generated feature is in the easy section.
* Confirm 1 generated feature is in the hard section.
* Confirm no generated feature is within 7 squares of the top edge.

* Confirm generated features do not overlap fixed board areas.
