* On later cave turns, Retreat should become enabled according to the existing cave rules.
* Do not remove or conditionally hide the Retreat button on the first turn.
* Keeping the button visible prevents layout shifting and makes the rule clearer to the player.

```txt id="nx3b0q"
First cave turn:
Go Deeper button visible and enabled.
Retreat button visible but disabled.

Later cave turns:
Go Deeper button visible and enabled.
Retreat button visible and enabled when retreat is allowed.
```

* The important requirement is that Retreat remains mounted and visible.

Fix 2: Cave Runner Prevented-Damage Message

* If the player has Cave Runner active and gets chased out by the ogre, Cave Runner prevents the health loss.
* The game currently shows something like:

```txt id="cy2sq3"
You lost 0 health
```

* This should not be shown.
* Instead, display a specific Cave Runner message.

Required Text

English:

```txt id="og2vm5"
You didn’t lose any health because the Cave Runner potion helped you get out before the ogre reached you.
```

Japanese:

```txt id="f3xf3h"
洞窟ランナーのポーションのおかげで、オーガに追いつかれる前に脱出できたため、HPを失いませんでした。
```

Display Requirement

* Show this message only when:

  * the player had Cave Runner active.
  * the ogre chase would normally have caused health loss.
  * Cave Runner prevented that health loss.
* Do not show `You lost 0 health`.
* Do not show the normal health-loss message with `0`.
* The message should appear in the same place where the cave failure health-loss text normally appears.
* Use the correct English/Japanese font.
* The text should follow the existing cave failure modal styling.

Suggested State Direction

```js id="91yel7"
const caveFailureResult = {
  healthLost: 0,
  preventedByCaveRunner: true
};
```

Suggested Display Direction

```jsx id="jwwmas"
<p className={`larger-text ${languageClass}`}>
  {caveFailureResult.preventedByCaveRunner
    ? caveRunnerPreventedDamageText
    : lostHealthText}
</p>
```

Cave Runner Consumption Requirement

* Preserve Feature-004 behaviour.
* Cave Runner should still be consumed when it prevents ogre damage.
* The player should still lose any cave prizes they had gained.
* Only the health damage is prevented.

Out Of Scope

* No changes to Cave Runner trigger rules.
* No changes to Cave Runner consumption rules.
* No changes to cave reward generation.
* No changes to ogre chase chance.
* No changes to Go Deeper behaviour.
* No changes to normal Retreat behaviour after the first cave turn.
* No unrelated Cave Mini Game redesign.
