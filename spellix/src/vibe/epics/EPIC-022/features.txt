Event Selection Requirement

* The weighted selection helper should ignore `0` values.
* The helper should not require every environment to have every event manually checked elsewhere.
* If a row total is not 100 in future, the helper should still work as weighted selection, but this feature’s rows should total 100.

Suggested weighted selection direction:

```js id="fk8zre"
function selectLandingEvent(environment) {
  const chances = environmentEventChances[environment];

  const entries = Object.entries(chances).filter(([, weight]) => weight > 0);
  const total = entries.reduce((sum, [, weight]) => sum + weight, 0);
  const roll = Math.random() * total;

  let runningTotal = 0;

  for (const [eventType, weight] of entries) {
    runningTotal += weight;

    if (roll < runningTotal) {
      return eventType;
    }
  }

  return entries[entries.length - 1][0];
}
```

* Use the project’s actual event names and helper structure.
* Do not introduce floating point edge-case crashes.
